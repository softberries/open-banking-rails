Command Palette

Centered narrow layout

Pages that don't need the full content width - settings, profile screens, forms with focused content - use mx-auto max-w-4xl on the outer wrapper so the content stays centered on wide displays instead of clinging to the left edge. Pair with an in-page side nav (grid lg:grid-cols-[220px_minmax(0,1fr)]) when sections need to be navigable; the aside collapses to a horizontal scroll strip below lg so adding more sections doesn't break the layout.

Live example: app/views/admin/settings/preferences/_layout.html.erb - drives /admin/settings/preferences. The aside iterates a registry helper (preferences_sections) so adding a tab is one entry + one controller action + one view.
